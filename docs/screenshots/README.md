# Meshtastic page mockups (v1.2.0)

**These are mockups, not device screenshots.** They were rendered at the T-Deck's 320x240 resolution
(shown here at 3x) with the firmware's unscii-8 font and terminal palette. The node names, IDs and
values are made-up example data.
